name: velt-verify
description: Verify a finished Velt surface against the design — drive states, confirm behavior, run the rules scan, emit a verdict. Use after building each surface (R15/R16).
---

Verification flow → verdict. **Measure the WHOLE surface, don't eyeball or sample.**

- Follow `guide/verifying-a-customization.md` step for step: drive **every** state → whole-surface **measured** delta check + a **mandatory visual side-by-side** → behavior check → static rules scan against `guide/rules.md`. Cross-cutting (a11y/dark/RTL/responsive): `guide/cross-cutting.md`. Stuck? `guide/debugging.md`.
- **Consume the GENERATED checklist** (`scripts/build-checklist.mjs --spec designSpec.json → checklist.json`: every distinct styled appearance + every `mustSupply` + every contract part + every state). You do NOT author a narrower spec. Inject `BROWSER_PROBE` from `scripts/delta-compare.mjs` `{surfaceSelector, tol, elements, relations, gaps}`; it diffs live `getComputedStyle` (style: ΔE<2, ±1px) AND surface-relative `getBoundingClientRect` (layout: box/gap/relation/missing). Produce `judge-report.json` with a disposition for **every** checklist element + the per-state visual artifact; `scripts/verdict-gate.mjs` decides done — **a sample (coverage < 100%) is INCOMPLETE, never PASS** (R26).
- **Gross-mismatch pre-check first** (total height / element count / extents) — a grossly-off surface FAILs before per-element work.
- **Visual gate is a GATE:** full-surface screenshot beside the Figma frame; **name every visible difference**; any nameable diff ⇒ FAIL.
- **Layer reconciliation (R22/R23):** for each painted node inject `LAYER_PROBE` (`scripts/delta-compare.mjs`) — FAIL on `ownerMismatch` (styled the wrong layer; the box doesn't match the design node — general R23) or any `neutralize[]` entry (a co-box wrapper still paints padding/bg/border the design applies once — general R22). It inspects box-painting only, never functional CSS.
- **Mount-map contract (R25) — the functional veto:** run `CONTRACT_PROBE` on the post-reconciliation DOM against the manifest's `contract.parts` — FAIL on any `MISSING`/`CONTAINMENT`/`CARDINALITY`/`PHANTOM_INTERACTIVE`. A boolean veto: a pixel-perfect surface with a broken mount map (absent primitive, hoisted-out-of-context part, duplicated singleton, custom control the SDK doesn't own) is a hard FAIL. PASS = visual ∧ layout ∧ contract.
- **Hard gates:** console error / unbuilt / `width===0` ⇒ BLOCKED/FAIL; every `mustSupply` slot ([`guide/reference/manifest.md`](../../guide/reference/manifest.md)) present + carrying the design's SVG/content (R17); no feature whose UI the design lacks (R24). **No aggregate score** — a goal is `met` only when style + layout deltas are empty for that state AND no nameable visual diff, with evidence; "looks close" or "5 props pass" is a FAIL. Verdict: `PASS | PARTIAL | FAIL | BLOCKED`. The verifier never declares the RUN done — it surfaces evidence; a separate evaluator (`/goal`) terminates. Unmet-but-no-clean-path → `velt-gap`.
